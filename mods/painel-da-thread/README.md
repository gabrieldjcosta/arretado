# painel-da-thread

Mostra o estado da thread atual do Claude Code: se está trabalhando ou esperando você, a barra de progresso das tarefas (lista do TodoWrite), os subagents invocados com cor por estado, o tempo do turno e a última ação. No desktop abre como painel lateral (comando /painel). Em telas sem painel, como o celular, aparece uma faixa de uma linha acima do campo de texto, com botão para ocultar. O mod enxerga só a sessão em que está instalado.

Instalar: `/plugin install painel-da-thread --marketplace gabrieldjcosta/arretado`.
