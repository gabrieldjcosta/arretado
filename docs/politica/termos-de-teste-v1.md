# Termos de teste — versão 1

Texto curto para quem entra no Arretado na fase de teste (V1), por convite. Durante o teste, o Arretado é gratuito.

## O que você está usando

- Uma versão de teste, ainda em construção. Coisas podem falhar ou mudar sem aviso.
- Sem garantia: o teste é "no estado em que está". Se algo não funcionar, relate (abaixo).
- Seus dados de estudo ficam no seu Aparelho. Não há sincronização automática entre Aparelhos nesta versão: guarde uma cópia com frequência (Conta › Dados, "Exportar" ou "Guardar cópia na nuvem").
- Apagar os dados do navegador ou perder o Aparelho sem cópia perde o estudo. Faça backup.
- A política de privacidade v3 vale para a conta: [`politica-de-privacidade-v3.md`](politica-de-privacidade-v3.md).

## Como relatar um Problema

- No app, o botão "!" abre o relato de Problema: descreva em poucas palavras o que aconteceu (um relato por Dia).
- [A DEFINIR PELO GABRIEL: canal direto para a V1 (e-mail ou outro), se houver.]

## Como sair e apagar

- Sair: Conta › Dados — "Sair". O Arretado pergunta se você mantém os dados no Aparelho ou apaga daqui. Use "Apagar daqui" em Aparelho emprestado ou compartilhado.
- Apagar tudo do Aparelho e da nuvem: Conta › Dados — "Excluir conta". É imediata e definitiva; exporte antes o que quiser guardar.
- Você pode continuar usando sem conta, como sempre.
