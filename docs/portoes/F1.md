## Para começar o uso real

1. Rodar localmente: `npm install` e `npm run build && npm run preview` (ou `npm run dev`).
2. Para usar no celular, o app precisa estar hospedado (arquivos estáticos; os dados continuam no aparelho) — decisão pendente com o Gabriel.
3. Fazer backup semanal em Conta › Dados › Exportar.
