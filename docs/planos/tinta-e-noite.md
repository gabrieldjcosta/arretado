## Como cada fase é entregue

- Um PR por fase, **em rascunho para a `integracao`**, no máximo 2 em voo; sai de rascunho com CI verde. O merge da `integracao` no `main` é só do Gabriel. `package.json`, `package-lock.json`, `.claude/settings.json` e `.claude/skills/` são caminhos protegidos (PR próprio, com o rótulo `aprovado-gabriel`). Só apresentação (D-D1).
- Pronto de uma fase: `npm run check` verde **na árvore enviada** (o gancho de commit não roda no clone da nuvem); `node scripts/contraste.mjs` verde nos dois temas; E2E das telas tocadas verde nos três projetos, com axe nos dois temas; `npm run build && npm run tamanho` (teto do JS do app: 425 kB gzip, só `dist/assets/*.js`); `node scripts/capturas-ui.mjs` nas telas da fase, com folhas "antes e depois" (claro e escuro; celular, tablet e desktop) em `docs/redesign/tinta-e-noite/<fase>/` (JPEG, até 500 kB por PR); docs atualizados (`glossario.md` se nasceu termo, `solucao-de-problemas.md` se houve tropeço).
- O contrato decide forma, cor, letra, movimento e o que é proibido; rotas, identificadores, vocabulário e dados não mudam. Nada de funcionalidade de fase posterior do produto.
